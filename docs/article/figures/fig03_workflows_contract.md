# Figure 3 Contract: Connected Scientific Access Workflows

## Five-Point Contract

- **Core conclusion:** TE-KG supports several connected entry routes to the
  same bounded evidence layers, allowing users to move from TE identity to
  relations, paths, expression, downloads, or cited answers.
- **Evidence chain:** runtime feature matrix -> representative browser checks ->
  source-visible outcomes.
- **Archetype:** schematic-led composite with annotated interface crops.
- **Backend:** plotting backend not needed for screenshots; any plotted summary
  inset must use the saved `nature-figure` backend.
- **Journal/export:** editable assembly master; screenshots at at least 300 dpi;
  sensitive/local development URLs removed from final labels.

## Proposed Panels

| panel | scientific question | action and visible outcome | status |
| --- | --- | --- | --- |
| A | What is known about a named TE? | Browse/Search to detail, classification, and source records | verified function; final crop pending |
| B | Which literature-supported entities connect to the TE? | Knowledge Graph and PMID-linked relation inspection | verified function; example chain pending |
| C | Is there a graph path between two named entities? | Path query with edge evidence | verified function; final example pending |
| D | How does expression vary by context? | Expression view across normal tissue, normal primary cell, and cancer cell line | verified function; final example pending |
| E | Can a user ask a cited follow-up question? | Agent/DeepThink answer with readable wording and PubMed links | session-scoped behavior verified; final example pending |
| F | Which underlying artifacts can be reused? | Download route showing ten currently exposed files | verified function; public release route pending |

## Integrity Risks

- presenting every page at equal weight instead of one connected workflow;
- exposing developer diagnostics, plugin names, or internal evidence flags;
- implying that a successful interface check establishes scientific accuracy;
- showing localhost as the final Database URL.
