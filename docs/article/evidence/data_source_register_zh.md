# TE-KG 数据来源登记表

最后复核：2026-08-03

本登记表用于区分上游数据来源与本地运行时存储位置。在数据来源的发布版
本、获取日期、许可证、主要引用、处理过程和运行时作用均得到记录以前，
不得将其视为可以直接写入论文终稿的来源。

本文档是数据来源、数据追溯、数据处理和数据发布待补事项的统一入口。
`docs/article/qa/` 下的审计文档用于保存补充证据和检查细节，不再作为另一套
相互独立的待办清单。

## 已核实的来源分工

### PubMed 与文献图谱

已有检索将 `DNA Transposable Elements` MeSH 词、TE 相关自由词和人类限定
条件组合使用。最终保留 2,308 篇论文，与当前 Neo4j 中的 `Paper` 节点数
一致。由于初始数量和中间筛选数量存在不一致，当前不能在论文中使用这些
中间数字。

### RMSK 与 RepBase

RMSK 衍生记录回答重复序列在人体基因组中被注释到什么位置。RepBase 衍生
记录回答 TE 身份、分类、描述、别名和代表性序列问题。论文不得把两者描述
成可以相互替代的数据来源。

数据提供者报告的 RepBase 浏览或导出地址为：

`https://www.girinst.org/repbase/update/browse.php?type=Transposable+Element&format=EMBL&autonomous=on&nonautonomous=on&simple=on&division=Homo+sapiens&letter=A`

该地址记录了物种、记录类型和 EMBL 输出格式，但没有固定的 RepBase release。
地址中还包含 `letter=A`，而本地文件同时包含 `L1HS`、`SVA_F` 等记录。因此，
从该页面得到当前 526 条本地记录的完整导出或合并过程，仍需由数据提供者确认。

每条记录中的 `DT` 字段不能代替整个导出数据集的 release。例如，本地 L1HS
记录于 2000 年在 release 5.05 中创建，并于 2006 年在 release 10.01 中最后
更新为 Version 3。这些日期只描述 L1HS 记录，不代表当前本地 RepBase 数据集
是“2006 年版”。

### 表达数据 accession

本地表达矩阵是衍生数据，而不是原始数据仓库文件的原样副本。因此，最终
Methods 必须同时引用原始 accession 或研究，以及本地预处理流程。运行时代码
为了兼容性继续使用 `normal_cell_line`，但论文和公开界面中的生物学名称应为
“正常原代细胞”（`normal primary cell`）。

## 阻断论文终稿的数据追溯缺口

1. RMSK 的准确基因组组装或表版本、来源 URL、获取日期和许可证。
2. RepBase 的准确 release、来源 URL、获取日期、完整导出过程和再分发规则。
3. ICD-11 的 release 和再利用说明。
4. 完整的表达数据预处理清单，包括参考基因组、注释版本、软件版本、标准化
   方法和样本排除规则。
5. SRP013565 中被作为正常原代细胞纳入的准确实验集合。
6. 三个表达矩阵的“原始 accession 到本地样本”对应表，并解决或明确排除重复
   标识符和五个无法匹配元数据的正常组织运行记录。
7. 准确的 PubMed 检索式、中间筛选数量、提取模型或端点版本，以及可复核的
   人工审核样本和判定记录。
8. 共表达所用的 HGNC 或其他基因参考版本、特征筛选规则、软件包版本和保存
   下来的敏感性分析结果。
9. TE-KG 输出文件的持久公开存档位置和文件级许可证。
10. 稳定、免费且无需登录的数据库网址，以及明确的维护和更新计划。

## 最终数据发布包完成条件

最终数据发布包应根据数据类型，为知识图谱、分类、表达、共表达、文献衍生
数据、Download 文件和论文图表来源数据提供以下信息：

- 发布名称、版本号和发布日期；
- 稳定文件名、格式、字节大小和 SHA-256 校验值；
- 上游来源、来源版本或 accession、获取日期和主要引用；
- 转换脚本或命令、参数、软件与软件包版本，以及输入到输出的对应关系；
- 每个文件的许可证和再分发状态；
- 稳定的 TE 标识符，以及图、分类、表达和共表达数据之间的名称对应关系；
- 样本级表达数据清单，包括原始 accession、本地样本标识、生物学情境、纳入
  或排除决定及其原因；
- 完整离线共表达网络、经批准的网页展示子集，以及连接二者的目录和参数版本；
- 文献检索式、保留的 PMID、衍生关系表和人工审核决定，但不重新分发受限制
  的论文全文；
- 论文图件和表 1 使用的冻结来源表；
- 带永久标识符的版本化代码存档和数据存档；
- 数据仓库元数据、无需登录的公开访问测试，以及维护和更新计划。

## 需要数据提供者或作者确认的事项

以下信息不能只根据本地文件时间推断，必须由数据提供者或作者确认：

- RepBase release、完整导出过程、获取日期和适用的再利用条款；
- RMSK/UCSC 来源表版本和获取信息；
- 表达样本的筛选和排除决定，特别是准确的 SRP013565 子集；
- 最终公开数据仓库、许可证和维护承诺。

在上游来源身份和发布范围确定后，文件校验值、运行时数量、文件清单、现有
转换脚本以及许多软件版本可以从当前仓库中生成或恢复。
