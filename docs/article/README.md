# TE-KG Article Workspace

This directory is the canonical home for manuscript-related materials.

Store the following here:

- journal requirements and template notes;
- analyses of representative papers;
- manuscript outlines and section drafts;
- figure and table plans;
- submission checklists;
- citation and data-availability notes.

## Current Files

- `database_journal_writing_examples.md`: evidence-based writing guidance derived
  from representative articles in *Database* and the journal's official author
  instructions.
- `nature_skills_workflow.md`: the gated manuscript-production workflow.
- `00_scope.md` through `05_style_guide.md`: the researchwrite foundation files
  controlling scope, facts, evidence, argument, section boundaries, and style.
- `evidence/`: source, content, runtime, evaluation, and literature registers.
- `figures/` and `tables/`: figure contracts, table plans, and the verified
  runtime snapshot table.
- `drafts/main.tex`: canonical OUP LaTeX working manuscript.
- `drafts/main.pdf`: compiled six-page working-draft PDF.
- `drafts/main_zh.tex` and `drafts/main_zh.pdf`: Chinese review translation;
  the English LaTeX project remains the only canonical submission source.
- `submission/TE-KG_working_draft_v0.1.docx`: Word review derivative generated
  from the canonical LaTeX source.
- `qa/`: LaTeX, Word, data, statistics, reference, and mock-review records.

The manuscript is a controlled working draft, not a submission package. Red
Draft notes and the QA reports identify unresolved provenance, public-release,
figure, and author inputs. Author Contributions remains deliberately deferred.
