# TE-KG 投稿缺口 / Submission Gap Register

Last reviewed / 最后核对：2026-08-06  
Target journal / 目标期刊：*Database: The Journal of Biological Databases and Curation*

## 1. 使用说明 / Usage

本文件只记录投稿前必须作出处理的事项。所谓“堵上缺口”，不一定意味着补做实验；可以采用以下三种方式之一：提供可核查证据、收窄或删除相应声明，或者确认该要求不适用并留下书面依据。不得用推测、模型常识、文件时间戳或临时本地网址填补事实。

This register contains only items that require a documented resolution. Closing a gap does not always require new experiments: the authors may provide verifiable evidence, narrow or remove the affected claim, or document why a conditional requirement does not apply. Inferred facts, model knowledge, file timestamps, and local development URLs are not acceptable substitutes.

### 阶段 / Phase

- **P0，初投前 / Before initial submission:** 未关闭时不应投稿。
- **P1，最晚返修或接收前 / No later than revision or acceptance:** 期刊允许稍后完成，但建议尽量在初投前完成，以避免评审无法核验。
- **C，条件项 / Conditional:** 必须在初投前确认是否触发；若触发，则按对应阶段完成。

### 判定依据 / Decision Basis

硬性要求优先依据当前 [*Database* Instructions to Authors](https://academic.oup.com/database/pages/instructions_for_authors)、[OUP Research Data guidance](https://academic.oup.com/pages/open-research/research-data) 和 [Database online submission guidance](https://academic.oup.com/database/pages/Submission_Online)。资源论文的正常评审要求参考期刊中的数据库与知识图谱论文，包括 [TOXIN KG](https://doi.org/10.1093/database/baae121)、[semantic queries across federated databases](https://doi.org/10.1093/database/baz106)、[semi-automated biological-network curation](https://doi.org/10.1093/database/bav057)、[graph databases in biomedicine](https://doi.org/10.1093/database/baab026)、[DPTEdb](https://doi.org/10.1093/database/baw078) 和 [FishTEDB](https://doi.org/10.1093/database/bax106)。这些论文用于判断审稿人通常需要看到的来源、模式、处理、追溯、定量内容、用例、限制和可用性证据，不把其个别写法误当成期刊硬性格式。

Mandatory requirements are taken first from the current official journal and OUP guidance linked above. Representative *Database* resource and knowledge-graph papers are used only to identify normal reviewer expectations for provenance, data modelling, processing, quantitative content, use cases, limitations, and availability.

## 2. 一票否决规则 / Submission Stop Rules

以下任一情况存在时，不应上传初稿：

- Word、LaTeX、图表、补充材料或投稿信中仍有红色 `Draft note`、`待补说明`、`AUTHOR_INPUT_NEEDED`、虚构 DOI/URL 或其他占位文字；
- 正式数据库仍只能通过本地地址访问，或需要登录、注册、密码或特殊网络环境；
- Data Availability 仍未给出真实可访问的位置、版本、许可证和标识符；
- 论文中的数据规模、来源版本、样本选择、处理流程或主要示例无法回溯到冻结文件和查询；
- 作者、单位、通讯作者、利益冲突、资助和原创性等投稿声明尚未由作者确认；
- 论文引用了尚未制作完成的图、表或补充材料。

Do not submit while any placeholder remains, while the resource is not publicly testable without authentication, while Data Availability contains promises rather than working access routes, while central claims cannot be traced to frozen evidence, while author declarations remain unconfirmed, or while cited figures, tables, or supplementary files do not exist.

## 5. 非硬性项 / Non-mandatory Items

- **Author Contributions：** 当前 *Database* 页面没有把独立贡献声明列为明确硬性正文部分。不要自行推断；若投稿系统要求，再由作者提供。
- **第二个 TE 用例：** 不是期刊明文硬性要求。若只完成 L1HS，应删除或收窄“可普遍覆盖多类 TE”的声明；若保留广泛性声明，第二个不同类型 TE 用例会成为必要证据。
- **Agent/DeepThink 的 36 题准确率：** 只要论文不宣称模型准确率或优于其他系统，就不必为了投稿强行报告总分；功能、引用完整性和边界仍需验证。
- **独立生物学发现：** 期刊是“强烈鼓励”数据库论文包含发现或可检验假设，并非明文接收条件。TE-KG 仍需至少一个有证据的具体用例，不能只做网页功能介绍。
- **Paperpal Preflight：** 官方明确为可选，不是投稿条件。
- **新序列数据库 accession：** 只有在论文报告新序列时触发。复用 RepBase 或 RMSK 记录时，重点是准确来源、版本、引用和再分发边界。
- **所有计划中的补充表和四张图：** 期刊不要求固定数量。真正的硬要求是：正文引用的每个图表必须存在并受证据支持；删去相关声明后，可相应删减图表。

- **Author Contributions:** not explicitly required as a standalone section by the current *Database* page; add only if the submission system requests it and authors supply the assignments.
- **A second TE use case:** not a formal journal requirement. It becomes necessary only if broad generality claims are retained.
- **A 36-question Agent/DeepThink accuracy score:** unnecessary when the manuscript makes no quantitative model-quality claim; functionality, citation integrity, and boundaries still require verification.
- **A new biological discovery:** strongly encouraged, not stated as an absolute acceptance condition. A concrete evidence-backed use case is still needed to support TE-KG's resource-value argument.
- **Paperpal Preflight:** optional according to the official instructions.
- **Sequence accessions:** triggered only by novel sequence reporting; reused records instead require exact provenance, citation, version, and redistribution handling.
- **A fixed number of figures or supplementary tables:** not required. Every item actually cited must exist and be evidence-backed, but unsupported planned items may be removed together with their claims.

## 6. 最小可投稿状态 / Minimum Submission-Ready State

只有同时满足以下条件，TE-KG 英文稿才可视为达到初投线：

1. 所有 **P0** 行均有真实证据或明确的删减决定，并标记关闭；
2. 所有 **C** 行已确认“适用”或“不适用”，没有悬而未决；
