this article workspace. A checked item means the working package contains the
required structure; it does not override unresolved red Draft notes.

- [ ] Free, login-free public resource deployed.

- [ ] Expression accession-to-sample manifest frozen.

  excluded.
- [ ] Literature query, screening counts, extraction model version, and manual
  audit records frozen.
- [ ] Co-expression comparison family, feature filtering, packages, and
  versions documented.
